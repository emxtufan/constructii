# Art direction — the construction record

An architectural project record: oversized compact typography, warm paper and
charcoal surfaces, thin numbered rules, gold/olive status accents, asymmetric
photo spreads and a technical drawing interlude, grounded in one documented site.
Continue the existing Green Tech logo, sans typography, dark navbar and 3D intro.

The existing concept illustration remains explicitly labeled as a concept; all
new photographic slots require authenticated user assets and meaningful captions.
Unfilled imagery receives a quiet lined document frame with honest pending text,
never a fictional construction scene. Unknown progress has no numeric percentage.
Current/complete/upcoming colors are assigned only to confirmed status data.

Visual rhythm: project introduction and stage index; large image-led stage story;
compact current snapshot; tactile material spread and editorial gallery; dark
blueprint; interactive before/current comparison; existing company principles;
future sequence and journal; native FAQ; spacious quote form; typographic closing.
The existing flow remains the company's Building Process and retains its engine
structure. Do not duplicate it with another generic process grid.

Motion: scoped IntersectionObserver entrances, limited translate/opacity and
image parallax only while visible on wide fine-pointer screens. No new scroll
owner, viewport pins, infinite animation or dependency. All text is visible by
default. Reduced motion disables entrances/parallax and preserves all controls.
Stage navigation works by mouse and keyboard; gallery uses an accessible dialog;
comparison uses a labeled native range with clear endpoints.

Mobile: ordinary document flow, stacked images, readable captions, horizontal
stage rail only when necessary with reachable buttons, large tap targets, no
fixed-height narrative or hover-only content. Tables/blueprint remain readable
without tiny pseudo-technical specifications. No fabricated dimensions or specs.
